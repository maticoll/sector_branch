# Asset and AI Research

## AI libraries

- Yuka: MIT JavaScript game AI library with steering, state/goal agents, navmesh, graph search, perception, triggers, and fuzzy logic.
- recast-navigation-js: WebAssembly Recast/Detour port for navmesh generation and pathfinding.
- navcat: pure JavaScript navmesh construction/querying library for floor-based 3D navigation.

## Asset sources

- Open Source 3D Assets: curated GLB/glTF collections with clear licensing, mostly CC0.
- FreePixel: free GLB game assets with characters, weapons, props, and buildings.
- Meshy: CC0 downloadable firearm and soldier model categories in GLB/OBJ/FBX-style formats.

## Recommendation

Use original CC0/royalty-free GLB assets for soldiers and weapons. Do not copy CS2 assets or exact skins. The right target is "CS2-inspired quality": realistic proportions, real weapon silhouettes, original colorways, and optimized LODs.
