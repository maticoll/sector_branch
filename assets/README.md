# Assets opcionales

El juego funciona sin estos archivos porque `main.js` crea fallbacks proceduralmente. Si queres mejorar el realismo, coloca assets gratuitos y legales con esta estructura:

```txt
assets/
  maps/
    map_warehouse/scene.glb
    map_desert/scene.glb
    map_container_yard/scene.glb
  weapons/
    pistol/weapon.glb
    smg/weapon.glb
    rifle/weapon.glb
    sentinel/weapon.glb
    sniper/weapon.glb
    shotgun/weapon.glb
  characters/
    ally/soldier.glb
    enemy/soldier.glb
  sounds/
    pistol_shot.mp3
    smg_shot.mp3
    rifle_shot.mp3
    sniper_shot.mp3
    shotgun_shot.mp3
    reload.mp3
    empty_click.mp3
    hit_enemy.mp3
    headshot.mp3
    impact_wall.mp3
    bomb_plant.mp3
    bomb_defuse.mp3
    explosion.mp3
    win.mp3
    lose.mp3
    footsteps.mp3
```

Fuentes recomendadas para buscar assets con licencia permisiva:

- Kenney: https://kenney.nl/assets
- Quaternius: https://quaternius.com/
- Poly Pizza: https://poly.pizza/
- Khronos glTF Sample Assets: https://github.com/KhronosGroup/glTF-Sample-Assets
- OpenGameArt: https://opengameart.org/

Verifica siempre la licencia concreta de cada asset antes de usarlo.
